# Матрица трассировки и проверок

Матрица связывает все функциональные требования с вариантами использования и ожидаемой проверкой. Это план приёмки документации, не результаты испытаний работающего сервиса.

| Требование | Сценарии | Проверка | Ожидаемый результат |
|---|---|---|---|
| FR-01 | UC-01 | TC-01 | Корректное подтверждение создаёт сессию; ошибка - нет. |
| FR-02 | UC-01, UC-07, UC-10 | TC-02 | Посетитель не открывает приватные данные; пользователь не получает права администратора. |
| FR-03 | UC-02 | TC-03 | Не заполнены обязательные поля или параметры недопустимы - оформление не подтверждается. |
| FR-04 | UC-02 | TC-04 | Для введённых параметров показаны доступные варианты, стоимость и срок, если источник их предоставляет. |
| FR-05 | UC-02 | TC-05 | Повтор одной операции подтверждения не создаёт второй заказ. |
| FR-06 | UC-03 | TC-06 | Поиск доступен без входа; неверный формат, отсутствие результата и недоступность источника различаются. |
| FR-07 | UC-04 | TC-07 | Операция связана с собственным заказом и зафиксированной суммой. |
| FR-08 | UC-04 | TC-08 | Повтор результата не меняет учёт повторно; возврат из браузера без подтверждения не означает успех. |
| FR-09 | UC-05 | TC-09 | Поиск по адресу работает при отказе от геолокации. |
| FR-10 | UC-06 | TC-10 | Можно выбрать доступный интервал; недоступный адрес или интервал не подтверждается. |
| FR-11 | UC-07 | TC-11 | По идентификатору чужого заказа доступ не выдаётся. |
| FR-12 | UC-07 | TC-12 | Изменения проходят валидацию; для защищаемых полей требуется подтверждение. |
| FR-13 | UC-08 | TC-13 | FAQ доступен без входа; зарегистрированное обращение получает идентификатор. |
| FR-14 | UC-09 | TC-14 | Показаны условия, получатель и подтверждённый результат действия. |
| FR-15 | UC-10 | TC-15 | Действия разрешены ролью и текущим состоянием заказа. |
| FR-16 | UC-10 | TC-16 | Сохранены идентификаторы исполнителя, заказа, время, действие и результат. |

## Проверки нефункциональных требований

NFR-01: нагрузочный прогон по согласованному профилю. NFR-02: мониторинг доступности за согласованный период. NFR-03/04: восстановление из резервной копии. NFR-05/07: проверки прав, подтверждений и ограничений попыток. NFR-06: проверка настроек защищённого соединения. NFR-08/09: проверки сценариев и интерфейса в согласованной матрице. NFR-10: проверка состава журналов и связности идентификаторов.

Параметры, помеченные открытыми, должны быть определены до утверждения критериев.
